# SmartSEV – Smart Electric Vehicle Monitoring Platform

An IoT-enabled monitoring platform designed to track and analyze electric vehicle usage, battery health, and solar integration for campus shuttle systems.

---

## 📌 Overview

SmartSEV is a real-time monitoring and analytics system built to optimize electric vehicle (EV) operations within a campus environment. The system provides live tracking, battery metrics, solar input monitoring, and intelligent alerting to improve operational efficiency.

The project emphasizes practical IoT deployment, real-time data pipelines, and dashboard visualization.

---

## ⚡ Key Features

- Live EV location tracking
- Battery percentage and health monitoring
- Solar charging analytics
- Real-time dashboard updates
- Event-based alerts and notifications
- Historical usage insights

---

**Backend**

**Database**
- MongoDB

**IoT & Messaging**
- MQTT Protocol

---

## ⚙️ System Architecture

1. Vehicle sensors collect telemetry data
2. Data transmitted via MQTT broker
3. Backend processes and stores real-time metrics
4. Frontend dashboard visualizes live vehicle status
5. Alerts generated based on predefined thresholds
